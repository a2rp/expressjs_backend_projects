# Express Backend Lab

A growing set of small Node.js and Express exercises for learning API fundamentals. The repository currently contains five beginner projects.

## Included projects

| Project | What it covers | Run command |
| --- | --- | --- |
| [01 - Hello World API](projects/01-hello-world-api/) | First JSON response | `npm run dev:01` |
| [02 - Static Response API](projects/02-static-response-api/) | Structured static JSON | `npm run dev:02` |
| [03 - Route Params API](projects/03-route-params-api/) | Dynamic route parameters | `npm run dev:03` |
| [04 - Query Filter API](projects/04-query-filter-api/) | Reading query parameters | `npm run dev:04` |
| [05 - Basic Routing API](projects/05-basic-routing-api/) | GET and POST routes with name validation | `npm run dev:05` |

## Run a project

Install dependencies once from the repository root:

```bash
npm install
```

Start one project at a time. Each example listens on `http://localhost:1198`:

```bash
npm run dev:01
```

Use the matching `api-test.rest` file in each project folder to send sample requests from VS Code. Project 05 keeps its example users in memory; restarting it clears any created users.

## Stack

Node.js, Express 5, and Nodemon. These examples are learning exercises, not production services.
