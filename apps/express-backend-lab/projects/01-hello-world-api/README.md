# 01 - Hello World API

Basic Express server that returns a JSON response.

---

## Description

This is the most basic Express.js application.

- Starts a server
- Creates a single route "/"
- Returns a JSON response

This is the foundation of all backend APIs.

---

## Run the Project

From root folder:

npm run dev:01

Or directly:

node projects/01-hello-world-api/index.js

---

## API Endpoint

GET /

http://localhost:1198

### Response

{
"message": "Hello World from Express Backend Lab"
}

---
